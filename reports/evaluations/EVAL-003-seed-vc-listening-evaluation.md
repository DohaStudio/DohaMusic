# EVAL-003 — Seed-VC 사용자 청취 평가

> 상태: 사용자 평가 대기
> Codex는 음원을 청취하거나 점수를 작성하지 않는다.

## 평가 준비 상태

| 항목 | 상태 |
|---|---|
| 출력 존재·길이·48kHz·stereo | 통과 |
| 무음 검사 | 통과 |
| clipping 위험 | 30-step 반복 3/3 경고, 해결 전 |
| 평가 음원 저장소 커밋 | 금지 |
| 참조 음성 동의 확인 | 사용자 확인 필요 |
| 사용자 청취 점수 | 미작성 |

## 평가 전 체크리스트

- [ ] 참조 음성의 소유자와 평가 목적 동의를 확인했다.
- [ ] 원본 보컬, 참조 음성, 변환 결과의 볼륨 차이가 평가를 왜곡하지 않는지 확인했다.
- [ ] 같은 재생 장치와 재생 볼륨에서 비교한다.
- [ ] 가능하면 파일명을 가린 상태로 원본/변환 결과를 비교한다.
- [ ] clipping 구간이 있다면 시간 위치와 청감 영향을 메모한다.
- [ ] 음원이나 개인정보를 Git에 추가하지 않는다.

## 평가 기준

점수 척도는 사용자가 평가 전에 정하고 모든 항목에 동일하게 적용한다. 점수만 남기지 않고 관찰 근거와 문제 구간을 함께 기록한다.

| 항목 | 확인 기준 | 점수/판정 | 근거·구간 |
|---|---|---|---|
| 음색 유사도 | 참조 음성의 고유한 음색이 유지되는가 |  |  |
| 발음 유지 | 원본 가사와 자음·모음이 훼손되지 않는가 |  |  |
| 노래 자연스러움 | 음정 전환과 프레이징이 자연스러운가 |  |  |
| 호흡 | 호흡 위치와 세기가 부자연스럽지 않은가 |  |  |
| 고음 | 고음에서 금속성·깨짐·음정 흔들림이 없는가 |  |  |
| 노이즈 | 잡음·버징·잔향·기계음이 거슬리지 않는가 |  |  |
| 활용 가능성 | 실제 DohaMusic 출력에 사용할 수 있는가 |  |  |

## 종합 결정

- [ ] 운영 가능
- [ ] 조건부 운영
- [ ] 운영 보류
- [ ] 제외

사용자 점수와 종합 결정이 비어 있으므로 Phase 4 완료 및 Seed-VC 운영 채택 근거로 사용할 수 없다. 현재 프로젝트의 기술 품질 게이트 판정은 별도로 **운영 보류**이며, 사용자 평가는 그 판정을 해제하기 위한 필수 조건이다.
