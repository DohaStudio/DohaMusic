# EVAL-002: Stem Separation 수동 청취 평가표

> 평가 상태: **사용자 입력 대기**  
> Codex 자동 점수: **작성하지 않음**  
> 연결 실험: [EXP-003](../experiments/EXP-003-stem-separation.md)

## 평가 대상

ignored 로컬 EXP-003 결과의 `vocals.wav`, `instrumental.wav`와 원본을 같은 재생 환경에서 비교한다. 파일명·경로는 평가자 환경에 맞게 기록한다.

| 항목 | 점수 또는 판정 | 근거·구간·메모 |
|---|---|---|
| 보컬 분리 | 사용자 입력 | 사용자 입력 |
| 반주 품질 | 사용자 입력 | 사용자 입력 |
| 보컬 누락 | 사용자 입력 | 사용자 입력 |
| 반주로의 보컬 누출 | 사용자 입력 | 사용자 입력 |
| 잔향·공간감 보존 | 사용자 입력 | 사용자 입력 |
| 인공 노이즈·아티팩트 | 사용자 입력 | 사용자 입력 |
| Seed-VC 입력 활용 가능성 | 사용자 입력 | 사용자 입력 |

## 종합 판정

- 채택 / 조건부 채택 / 재검토: **사용자 입력**
- 재실험이 필요한 구간: **사용자 입력**
- 다음 Phase 진입 의견: **사용자 입력**

자동 검증은 파일 존재, 48kHz, Stereo, 동일 길이, 비무음, clipping만 확인한다. 이 값은 청감 품질 점수를 대신하지 않는다.
