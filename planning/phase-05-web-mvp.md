# Web MVP 계획 연결

> 문서 상태: [대체됨]
> 최종 수정일: 2026-07-31
> 대체 문서: [Doha Studio Frontend Roadmap](frontend-roadmap.md)

기존 생성 폼 중심 Web MVP 계획은 Premium AI Music Studio 설계로 대체됐다. 실제 Frontend 구현은 Phase 8이며 현재 상태는 `[계획]`이다.

새 설계는 responsive workspace, Music Settings → Lyrics → Voice → Review → Generation → Result 흐름, Design System, Atomic Components, API polling과 접근성·오류·복원 기준을 포함한다. 현재 Backend에 없는 upload/download·audio content·history·cancel/retry·인증·소유권 기능은 [Frontend Roadmap](frontend-roadmap.md)의 선행 계약으로 관리한다.
