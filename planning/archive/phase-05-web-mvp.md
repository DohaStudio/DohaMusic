기존 생성 폼 중심 Web MVP 계획은 Premium AI Music Studio 설계로 대체됐다. 실제 Frontend 로컬 MVP는 Phase 8에서 `[완료]`됐고 사용자 안내형 Voice Enrollment는 F6 `[계획]`으로 분리됐다.

새 설계는 responsive workspace, Music Settings → Lyrics → Voice → Review → Generation → Result 흐름, Design System, API polling과 접근성·오류·복원 기준을 포함한다. Voice Profile upload, Pipeline WAV content/download, History·Project와 cancel/retry는 구현됐다. 브라우저 녹음·다중 sample·Enrollment 상태와 인증·소유권은 [Frontend Roadmap](../frontend-roadmap.md)의 F6·Phase 9 선행 계약으로 관리한다.
