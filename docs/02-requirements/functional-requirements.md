# 기능 요구사항

> 문서 목적: MVP 기능을 추적 가능한 요구사항으로 정의한다.
> 현재 상태: **Phase 3 Stem Separation 반영**

| ID | 요구사항 | 상태 |
|---|---|---|
| FR-001 | 프롬프트 또는 직접 작성 가사를 입력한다. | [Foundation 완료] |
| FR-002 | 장르, 분위기, BPM, 곡 길이, Seed를 선택적으로 지정한다. | [부분 완료: 장르·곡 길이·Seed] |
| FR-003 | 유효한 요청으로 비동기 생성 작업을 만든다. | [Foundation 완료: 내부 Mock Worker] |
| FR-004 | 사전학습 모델로 노래를 생성한다. | [검증 필요] |
| FR-005 | 생성 음원에서 보컬과 반주를 분리한다. | [기술 완료: Mock·HTDemucs, 청취 평가 필요] |
| FR-006 | 동의가 유효한 참조 음성을 업로드하고 음성 프로필을 만든다. | [부분 완료: 동의 확인 메타데이터] |
| FR-007 | 분리 보컬의 음색을 선택한 프로필로 변환한다. | [검증 필요] |
| FR-008 | 보컬과 반주를 재결합하고 보컬·반주·전체곡을 출력한다. | [계획] |
| FR-009 | WAV 저장과 선택적 MP3 변환을 제공한다. | [부분 완료: 생성·Stem WAV 저장] |
| FR-010 | 상태, 진행률, 오류, 취소, 재시도를 제공한다. | [부분 완료: 상태·오류 조회] |
| FR-011 | 이력에서 설정·모델·버전·Seed·파일을 확인한다. | [부분 완료: 요청·Seed·파일 메타데이터] |

검증 가능한 행위는 [인수 기준](acceptance-criteria.md), API는 [API 개요](../06-api/api-overview.md)에 매핑한다.

`Foundation 완료`와 `부분 완료`는 전체 제품 기능 완료를 의미하지 않는다. ACE-Step과 HTDemucs는 선택적 실험 Provider이며 사용자 청취 평가가 남아 있다. Seed-VC·믹싱·MP3·인증은 구현하지 않았다.
