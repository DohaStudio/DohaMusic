## 포함

- 직접 작성 가사와 음악 스타일 프롬프트 입력
- 사전학습 모델을 사용한 노래 생성
- 보컬·반주 분리와 동의된 참조 음성의 음색 변환
- 변환 보컬과 반주 재결합, WAV 저장
- 작업 상태·오류·재시도와 생성 이력

MP3는 편의 변환 기능으로 계획하지만 WAV 성공을 MVP 완료 기준으로 삼는다.

## 제외

- 기반 모델 직접 사전학습, 실시간 가창, 대규모 서비스, 결제
- 모바일 앱, 전문 DAW 편집, 자동 회원 소통
- 타인 음성 무단 복제

세부 단계는 [로드맵](../../ROADMAP.md), 범위 검증은 [인수 기준](acceptance-criteria.md)을 따른다.
