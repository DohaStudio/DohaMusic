# 비기능 요구사항

> 문서 목적: 성능, 안정성, 보안, 운영 및 확장 기준을 정의한다.
> 현재 상태: **초안 / 목표값 검증 필요**

- NFR-001 자원: RTX 3060 Ti 8GB에서 모델을 순차 로드·해제하고 필요 시 CPU offload를 지원하도록 설계한다.
- NFR-002 안정성: 긴 작업은 비동기 처리하며 실패 단계·오류 코드·재시도 가능 여부를 기록한다.
- NFR-003 재현성: 모델·버전·설정·Seed·입력 해시·파이프라인 버전을 보존한다.
- NFR-004 보안: 업로드 형식·크기·접근 권한을 검증하며 실행 파일로 해석하지 않는다.
- NFR-005 프라이버시: 원본 음성, 파생 파일, 동의 기록의 최소 수집·삭제·감사를 지원한다.
- NFR-006 이식성: 모델과 저장소는 어댑터로 교체 가능해야 한다.
- NFR-007 관측성: 작업 ID로 API·Worker·모델 실행 로그를 연결한다.

구체 목표값은 [벤치마크 시나리오](../08-evaluation/benchmark-scenarios.md) 실측 후 승인한다.
