# 사용자 스토리

> 문서 목적: 사용자 관점의 기대와 정책 제약을 요구사항에 연결한다.
> 현재 상태: **초안**

- US-001 창작자로서, 가사와 분위기를 입력해 노래 초안을 만들고 싶다.
- US-002 창작자로서, 내 동의된 음성 프로필로 생성 보컬의 음색을 바꾸고 싶다.
- US-003 사용자로서, 긴 작업의 현재 단계와 진행률을 확인하고 싶다.
- US-004 사용자로서, 실패 원인과 재시도 가능 여부를 알고 싶다.
- US-005 사용자로서, 결과의 모델·버전·Seed·설정을 확인하고 싶다.
- US-006 음성 권리자로서, 동의를 철회하고 원본·파생 음성을 삭제하고 싶다.

흐름은 [사용자 시나리오](../00-overview/user-scenarios.md), API 판정은 [인수 기준](acceptance-criteria.md)에 있다.
