# 모델 로딩 전략

> 문서 목적: 제한된 VRAM에서 모델 생명주기와 캐시 정책을 정의한다.
> 현재 상태: **설계 초안 / 실측 필요**

기본 전략은 한 시점에 한 단계의 주 모델만 GPU에 올리는 것이다. 단계 종료 후 참조 해제, 프레임워크 캐시 정리, 메모리 측정을 수행하고 다음 모델을 로드한다.

선택적 최적화는 CPU offload, 정밀도 축소, 청크 처리 순으로 후보별 검증한다. 정밀도나 설정 변경은 품질과 재현성에 영향을 주므로 실행 로그에 남긴다. 동시 실행 수는 [GPU 메모리 전략](gpu-memory-strategy.md)의 벤치마크 결과로 결정한다.
