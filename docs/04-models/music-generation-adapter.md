# 음악 생성 어댑터

> 문서 목적: 음악 생성 모델 교체를 위한 입력·출력·오류 계약을 정의한다.
> 현재 상태: **인터페이스 설계**

입력은 정규화된 prompt, 선택적 lyrics, duration_seconds, seed와 모델 설정이다. 출력은 검증된 오디오 파일과 실제 Seed, 샘플레이트, 모델·버전, 실행 설정 메타데이터다.

어댑터는 모델 고유 프롬프트 변환과 로딩을 캡슐화하며 작업 생성, 사용자 권한, 영구 저장을 책임지지 않는다. 지원하지 않는 가사·길이·Seed는 조용히 무시하지 않고 명시적 capability 오류를 반환한다.
