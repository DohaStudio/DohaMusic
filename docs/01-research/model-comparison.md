# 모델 비교

> 문서 목적: 후보 모델을 동일 근거와 상태로 비교하고 도입 결정을 추적한다.
> 현재 상태: **초기 후보 / 수치 검증 전**

추정 수치를 기입하지 않는다. 공식 자료 확인과 로컬 테스트가 끝나면 출처 또는 보고서 링크를 함께 기록한다.

| 모델명 | 기능 | 입력 | 출력 | 한국어 | 가사/멜로디 제어 | VRAM/속도 | 파인튜닝 | 라이선스/상업 이용 | 장점·단점 | 도입 상태 | 검증 결과 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| ACE-Step 계열 후보 | 음악·가창 생성 | 프롬프트, 가사 등 | 오디오 | 공식 문서 확인 필요 | 검증 필요 | 로컬 테스트 필요 | 확인 필요 | 라이선스 검토 필요 | 통합 생성 후보 / 8GB 적합성 미확인 | 검증 필요 | 미실행 |
