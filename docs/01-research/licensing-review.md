# 라이선스 검토

> 문서 목적: 코드·가중치·데이터셋·출력 사용 조건을 모델별로 판정하는 절차를 정의한다.
> 현재 상태: **정책 초안 / 개별 후보 검증 필요**

## 검토 단위

모델마다 코드 저장소, 가중치, 학습 데이터 또는 데이터 설명, 추론 의존성, 데모 음성, 모델 출력 약관을 분리해 확인한다. 코드 라이선스만으로 가중치나 상업적 이용을 허용한다고 판단하지 않는다.

## 판정 항목

- 정확한 이름·버전·출처 URL·확인일
- 수정·재배포·서비스 제공·상업 이용 가능 여부
- 표시, 고지, 사용 제한, 파생물 조건
- 음성·음악·데이터 권리와 관할 리스크

미확인 항목이 하나라도 핵심 사용을 막을 수 있으면 상태를 `보류`로 둔다. 법률 자문이 필요한 사안은 기술 문서에서 단정하지 않는다.
