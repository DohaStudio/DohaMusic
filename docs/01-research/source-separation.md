# 음원 분리 모델 조사

> 문서 목적: 보컬과 반주 분리 후보의 품질·자원·권리 기준을 정의한다.
> 현재 상태: **후보 조사 / 검증 필요**

Demucs 및 호환 가능한 Stem separation 모델을 검토한다. 2-stem 출력, 샘플레이트, 긴 음원 분할, CPU/GPU 실행, 최대 VRAM, 처리 시간, 보컬 누출과 반주 손상을 측정한다.

변환 단계에는 보컬 Stem만 전달하고, 원본과 중간 Stem은 작업 권한과 보존 정책을 적용한다. 공통 비교 항목은 [모델 비교](model-comparison.md)를 따른다.
