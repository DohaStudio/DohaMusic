# 음색 변환 모델 조사

> 문서 목적: 생성 보컬을 동의된 개인 음색으로 변환할 후보와 검증 항목을 정의한다.
> 현재 상태: **후보 조사 / 검증 필요**

Seed-VC 계열을 후보로 검토한다. zero-shot/파인튜닝 방식, 가창 입력 지원, F0 보존, 한국어 발음 보존, 참조 길이, 잡음 민감도, VRAM, 라이선스를 확인한다. 말하기 데모 성능을 가창 성능으로 간주하지 않는다.

음색 유사도만 높고 발음·멜로디가 훼손되는 후보는 채택하지 않는다. 데이터 사용은 [음성 동의 정책](../09-security/voice-consent-policy.md), 평가는 [음색 유사도 평가](../08-evaluation/voice-similarity-evaluation.md)를 따른다.
