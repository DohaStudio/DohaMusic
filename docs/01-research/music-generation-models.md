# 음악 생성 모델 조사

> 문서 목적: 가사·프롬프트 기반 음악 생성 후보의 조사 기준을 정의한다.
> 현재 상태: **후보 조사 / 검증 필요**

## 후보

- ACE-Step 계열: 가사 조건, 한국어, 출력 형식, VRAM, 상업 이용 조건을 공식 문서와 로컬 테스트로 확인한다.
- 그 밖의 공개 모델: 동일 평가표를 통과한 경우에만 비교군에 추가한다.

## 필수 검증

모델 버전과 가중치 출처, 입력 길이, 가사 제어, 샘플레이트, 추론 시간, 최대 VRAM, CPU offload, 재현성, 라이선스, 상업 이용 가능 여부를 기록한다. 확인되지 않은 값은 `검증 필요`로 남긴다.

실험은 [모델 테스트 템플릿](../../reports/model-test-template.md), 선정은 [모델 비교](model-comparison.md)를 사용한다.
