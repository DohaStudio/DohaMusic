# 가창 음성 합성 조사

> 문서 목적: 가사·음높이에서 가창을 합성하는 기술과 개인화 가능성을 조사한다.
> 현재 상태: **장기 후보 / 검증 필요**

DiffSinger 계열을 포함하되 특정 구현을 확정하지 않는다. 한국어 음소 처리, 악보/피치 입력 요구, 데이터 준비 비용, 추론 VRAM, 파인튜닝 방식, 가중치와 데이터셋 라이선스를 별도로 검증한다.

MVP는 통합 음악 생성 결과의 보컬을 음색 변환하는 방식을 우선하며, 전용 개인 가창 모델은 [Phase 7](../../ROADMAP.md)에서 안전·품질·비용을 재평가한다.
