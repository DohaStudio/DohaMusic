# Frontend 아키텍처

> 문서 목적: Next.js 웹 MVP의 화면·상태·API 경계를 정의한다.
> 현재 상태: **설계 초안**

주요 화면은 생성 폼, 음성 프로필 관리, 작업 상세, 결과 플레이어, 생성 이력이다. 서버 상태는 작업 ID를 기준으로 주기 조회하며 종료 상태에서 중단한다. 페이지 새로고침 뒤에도 URL로 작업을 복원한다.

브라우저는 저장소 경로나 내부 모델 오류를 직접 다루지 않는다. 업로드 전 형식·크기를 안내하되 서버 검증을 대체하지 않는다. 동의 확인은 명시적 행동과 정책 버전을 함께 제출한다.
