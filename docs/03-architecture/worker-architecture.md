# AI Worker 아키텍처

> 문서 목적: GPU 작업 실행, 자원 관리, 취소·재시도 규칙을 정의한다.
> 현재 상태: **설계 초안**

Worker는 원자적으로 작업 실행권을 획득하고 lease/heartbeat로 중복 실행을 감지한다. 단계 진입 전 취소·동의 상태를 확인하고, 모델 로드 → 추론 → 출력 검증 → 모델 해제 순서를 보장한다.

8GB VRAM 환경에서는 여러 모델의 동시 상주를 전제하지 않는다. OOM 발생 시 캐시 정리, 선택적 CPU offload 또는 더 낮은 안전 설정으로 한정된 재시도를 수행하며 품질을 몰래 낮추지 않고 실행 설정에 기록한다.

모델 로딩은 [로딩 전략](../04-models/model-loading-strategy.md), 상태는 [작업 상태 모델](../07-database/job-state-model.md)을 따른다.
