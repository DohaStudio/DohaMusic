# 사용자 시나리오

> 문서 목적: 대표 사용 흐름과 안전 실패 흐름을 정의한다.
> 현재 상태: **초안**

## 시나리오 A: 직접 작성 가사로 곡 생성

1. 사용자가 가사와 장르·분위기·BPM·길이를 입력한다.
2. 시스템이 요청을 검증하고 비동기 작업을 생성한다.
3. 음악 생성, Stem 분리, 선택한 음성 프로필 변환, 믹싱을 순차 수행한다.
4. 사용자는 진행률과 오류를 보고, 완료 후 WAV를 재생·다운로드한다.

## 시나리오 B: 프롬프트만으로 초안 생성

가사 없이 음악 프롬프트를 제출한다. 가사 자동 생성 지원 여부는 모델별 능력과 권리 검토 후 활성화하며 현재는 `[검증 필요]`다.

## 시나리오 C: 동의 없는 음성 차단

유효한 동의 기록이 없거나 철회된 음성 프로필을 선택하면 검증 단계에서 실패한다. 작업은 GPU 실행 전에 종료되고 감사 가능한 오류 코드를 남긴다.

세부 요구사항은 [사용자 스토리](../02-requirements/user-stories.md)와 [인수 기준](../02-requirements/acceptance-criteria.md)을 따른다.
