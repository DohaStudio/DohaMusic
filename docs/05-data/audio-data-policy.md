# 오디오 데이터 정책

> 문서 목적: 입력·중간·결과 오디오의 수집, 접근, 보존과 삭제 원칙을 정의한다.
> 현재 상태: **정책 초안**

필요한 오디오만 목적별로 수집하고 사용자·작업 단위로 격리한다. 원본 참조 음성은 민감 데이터로 취급하며 암호화 저장, 최소 권한, 접근 감사가 필요하다. 중간 Stem은 작업 완료 후 기본 삭제 후보이고 최종 결과는 사용자가 관리한다.

각 파일은 소유 사용자, 작업, 유형, 해시, MIME, 크기, 보존 상태를 기록한다. 동의 철회·계정 삭제 시 [음성 동의 정책](../09-security/voice-consent-policy.md)의 삭제 범위를 적용한다. 실제 보존 기간은 운영·법적 요구 검토 후 확정한다.
