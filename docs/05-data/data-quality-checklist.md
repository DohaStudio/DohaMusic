# 데이터 품질 체크리스트

> 문서 목적: 참조 음성과 실험 데이터의 수용 여부를 일관되게 판정한다.
> 현재 상태: **초안**

- [ ] 유효한 동의 기록과 소유자 연결
- [ ] 허용된 파일 형식·크기·길이
- [ ] 디코딩 성공, 예상 채널·샘플레이트
- [ ] 클리핑·긴 무음·심한 배경 잡음 확인
- [ ] 여러 화자·배경 음악 혼입 확인
- [ ] 전사와 언어·가창/말하기 라벨 확인
- [ ] 해시·전처리 버전·품질 판정 기록
- [ ] train/validation/test 화자·곡 누출 방지

모델별 임계값은 로컬 실험 전에는 확정하지 않는다.
