# 생성 콘텐츠 정책

> 문서 목적: 생성 결과의 출처 표시, 권리 고지, 접근과 삭제 원칙을 정의한다.
> 현재 상태: **정책 초안 / 법률 검토 필요**
> 최종 수정일: 2026-08-05
> 관련 문서: [DohaLM 연동](../03-architecture/dohalm-integration.md), [라이선스 검토](../01-research/licensing-review.md), [가사 버전 데이터 모델](../07-database/lyrics-versioning-data-model.md)

모든 결과에는 AI 생성 여부, 생성 시각, 모델·버전, 설정, 입력·음성 프로필 참조, 파이프라인 버전을 메타데이터로 기록한다. 공개 표시 방식과 워터마킹은 제품 단계에서 별도 결정한다.

사용자는 가사·음성·참조 자료에 필요한 권리를 보유해야 한다. 모델 출력의 저작권·상업 이용 가능성을 서비스가 보증하지 않으며 모델별 라이선스와 관할 법률 검토가 필요하다. 결과 접근과 삭제는 소유 사용자에게 제한한다.

Lyrics 입력은 길이를 제한하고 제어 문자와 script/style·HTML을 저장 전에 제거한다. API·Provider 오류 로그에는 전체 topic·가사·추가 지시를 남기지 않는다. 특정 기존 곡의 가사를 그대로 재현하거나 장문 복제하는 용도는 지원하지 않으며 외부 LLM 도입 시 유사성·권리 정책을 다시 검토한다. 현재 Template은 로컬 규칙 기반 초안으로 실제 LLM 생성물과 구분한다.

## DohaLM 가사 공동 창작 정책 — [계획]

DohaLM이 생성한 가사는 창작 보조용 초안이다. 사용자는 생성 결과를 검토하고 직접 수정·선택·배열·삭제·추가 또는 보완한 뒤 최종 승인해야 한다. 승인되지 않은 AI 최초 생성본과 AI 수정 제안은 음악 생성 Pipeline으로 전달하지 않는다.

상업적으로 이용되는 최종 가사는 사용자 승인 버전이어야 한다. 다만 사람의 수정이나 승인이 저작권 발생을 자동으로 보장하지 않으며, 모델·가중치·학습 데이터의 라이선스 제한을 해제하지도 않는다. 상업 작업에는 모델·가중치·전체 데이터 계보의 검토 상태가 `commercial_approved`인 Provider만 선택할 수 있다.

시스템은 다음 정보를 서로 구분해 저장한다.

- 사용자 입력
- AI 최초 생성본
- AI 수정 제안
- 사용자 수정본
- 최종 승인본
- 사용 모델명·버전·manifest 식별자
- 생성 시각과 승인 시각
- 상업 이용 검토 상태

## 권리와 유사성 주의사항

- 사용자는 프롬프트·기존 가사·참조 자료에 필요한 권리를 보유해야 한다.
- 타인의 기존 가사와 실질적으로 유사한 결과는 사용하지 않는다.
- 특정 가수·작사가의 스타일을 그대로 모방하도록 유도하지 않는다.
- 최종 상업 이용 전 별도 유사성 및 권리 검토가 필요하다.
- `research_only`, `commercial_review_pending`, `commercial_rejected` 모델 결과는 상업 작업에 사용할 수 없다.
- DohaLM의 `AIHUB-71748` 계열은 비상업 연구 범위이므로 상업용 DohaMusic Provider로 선택하지 않는다.

이 문서는 제품 안전 정책이며 법률 자문을 대체하지 않는다. 관할 법률, 서비스 방식과 실제 배포 artifact를 기준으로 별도 법률 검토가 필요하다.
