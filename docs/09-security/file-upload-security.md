# 파일 업로드 보안

> 문서 목적: 오디오 업로드의 검증·격리·처리 요구사항을 정의한다.
> 현재 상태: **설계 초안**

- 허용 목록 기반 확장자·MIME를 사용하되 실제 디코딩으로 확인한다.
- 파일 크기·길이·채널·샘플레이트 제한을 서버에서 적용한다.
- 사용자 파일명을 저장 경로로 사용하지 않고 무작위 ID와 논리 키를 쓴다.
- 업로드를 실행 코드나 셸 인자로 해석하지 않는다.
- 임시 영역에 격리하고 검증 실패 시 안전하게 삭제한다.
- 압축 폭탄, 경로 이동, 다중 형식(polyglot), 악성 메타데이터를 고려한다.

정확한 허용값은 모델·운영 부하 테스트 후 확정한다.
