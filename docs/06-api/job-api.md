# 작업 API

> 문서 목적: 비동기 생성 작업의 현재 조회 계약과 후속 범위를 정의한다.
> 현재 상태: **조회 구현 완료 / 취소·재시도 미구현**

`GET /api/generations/{id}`는 상태, 현재 단계, 입력 스냅샷, 오류와 시각 정보를 반환한다. 유효 상태와 전이는 [작업 상태 모델](../07-database/job-state-model.md)을 따른다.

존재하지 않는 Job은 `404 RESOURCE_NOT_FOUND`를 반환한다.

다음 기능은 Phase 1에 포함되지 않는다.

- Job 취소
- 실패 Job 재시도
- 진행률 백분율
- 프로세스 재시작 후 대기 Job 복구
- 외부 Queue 기반 분산 실행
