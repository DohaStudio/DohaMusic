# 작업 API

> 문서 목적: 비동기 작업 조회, 취소와 재시도 계약을 정의한다.
> 현재 상태: **설계 초안 / 미구현**

- `GET /api/v1/jobs/{job_id}`: 상태, 현재 단계, 진행률, 시각, 오류, 결과 링크 조회
- `POST /api/v1/jobs/{job_id}/cancel`: 취소 요청; 이미 종료된 작업에는 멱등 응답
- `POST /api/v1/jobs/{job_id}/retry`: 재시도 가능한 실패에서 새 실행 생성

재시도는 원본 요청 스냅샷과 이전 실행을 보존하며 새 작업 ID를 발급한다. 상태 전이는 [작업 상태 모델](../07-database/job-state-model.md)을 기준으로 한다.
