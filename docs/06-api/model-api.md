# 모델 API

> 문서 목적: 사용자와 운영자가 확인할 모델 capability·가용성 계약을 정의한다.
> 현재 상태: **후속 단계 계획 / Phase 1 미구현**

- `GET /api/models`: 활성 모델의 기능, 입력 제한, 라이선스 검토 상태를 조회한다.
- `GET /api/models/{model_id}`: 버전, capability, 가용 상태, 검증 상태를 조회한다.
- 내부 운영용 상태 변경 API는 사용자 API와 분리하고 강한 권한을 요구한다.

미검증 모델은 기본 선택지로 노출하지 않는다. 모델 파일 경로나 내부 로딩 오류는 공개 응답에 포함하지 않는다.
