# ADR-004: 개인 음성 데이터 정책

> 문서 목적: 개인 음성의 동의·사용·철회·삭제를 강제하는 결정을 기록한다.
> 상태: **승인 제안**
> 현재 상태: 초기 설계

## 배경

음색 변환에는 식별 가능하고 오용 위험이 큰 개인 음성이 사용된다.

## 결정

본인 또는 명시적 사용 동의를 받은 음성만 등록한다. 동의 증적, 사용 provenance, 철회, 원본·파생 데이터 삭제를 제품 데이터 모델과 실행 검증에 포함한다.

## 선택 이유와 대안

경고문만 제공하는 대안은 실제 실행과 데이터 수명을 통제하지 못한다. 강제 동의 검사는 구현 부담이 있지만 핵심 제품 요건이다.

## 장점·단점·영향

권리 보호와 감사 가능성이 높아지는 대신 데이터 모델, 저장소 삭제, 작업 중 재검사, 사용자 경험이 복잡해진다. [음성 동의 정책](../09-security/voice-consent-policy.md)을 기준으로 구현한다.

## 재검토 조건

법률·정책 변경, 공유 프로필 도입, 개인화 학습 진입 시 범위와 보존을 재검토한다.
