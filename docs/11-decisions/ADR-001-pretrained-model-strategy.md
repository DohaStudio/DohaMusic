# ADR-001: 사전학습 모델 채택 전략

> 문서 목적: 기반 모델 자체 학습 대신 사전학습 모델을 우선하는 결정을 기록한다.
> 상태: **승인 제안**
> 현재 상태: 초기 설계

## 배경

개인 GPU 환경, 대규모 학습 데이터 확보와 사전학습 비용, 개발 기간 때문에 기반 음악 생성 모델을 처음부터 학습하기 어렵다.

## 결정

공개 사전학습 모델을 도입해 추론·통합 파이프라인을 먼저 구축한다. 특정 모델은 고정하지 않고 선정 게이트를 통과한 어댑터로 교체한다.

## 선택 이유와 대안

통합 위험을 먼저 검증하고 데이터·비용 부담을 낮춘다. 대안인 자체 사전학습은 MVP 비목표이며 개인화 파인튜닝은 Phase 7에서 검토한다.

## 장점·단점·영향

개발 속도와 교체성은 높지만 외부 모델 품질·라이선스·공급에 의존한다. 따라서 [라이선스 검토](../01-research/licensing-review.md)와 로컬 벤치마크가 필수다.

## 재검토 조건

후보가 한국어·8GB·권리 게이트를 충족하지 못하거나 개인화 데이터가 충분히 확보될 때 재검토한다.
