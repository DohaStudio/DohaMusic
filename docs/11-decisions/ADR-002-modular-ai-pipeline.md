# ADR-002: 모듈형 AI 파이프라인

> 문서 목적: AI 처리 단계를 교체 가능한 모듈로 분리하는 결정을 기록한다.
> 상태: **승인**
> 현재 상태: Phase 1 인터페이스 경계 구현

## 배경

음악 생성, Stem 분리, 음색 변환, 믹싱은 라이브러리·자원·입출력이 다르고 후보 교체 가능성이 높다.

## 결정

각 단계를 독립 어댑터와 명시적 파일·메타데이터 계약으로 분리한다.

Phase 1에서는 첫 경계인 `MusicGenerator` Protocol과 `MockMusicGenerator`를 구현했다. 실제 모델 Adapter와 나머지 단계는 후속 Phase에서 같은 원칙으로 추가한다.

## 선택 이유와 대안

단일 모델/스크립트 결합보다 단계별 검증·교체·재시도가 쉽다. 반면 중간 파일과 오케스트레이션 복잡도가 증가한다.

## 영향

공통 인터페이스, 단계별 상태, provenance, 임시 파일 정책이 필요하다. 기준은 [AI 파이프라인](../03-architecture/ai-pipeline.md)에 둔다.

## 재검토 조건

한 모델이 모든 단계를 더 안전하고 효율적으로 제공하거나 중간 I/O가 병목이 될 때 재검토한다.
